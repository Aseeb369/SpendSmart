# SpendSmart 💰

SpendSmart is a simple and user-friendly **Expense Tracking Web Application** built using **ASP.NET Core MVC (.NET 8)**. It helps users manage daily expenses by adding, editing, deleting, and categorizing expenses while also providing an overview of spending by category.

## 🚀 Features

* ➕ Add new expenses
* ✏️ Edit existing expenses
* ❌ Delete expenses
* 📂 Category-based expense tracking
* 📊 Expense Overview dashboard
* ✅ Form validation for invalid inputs
* 🔢 Automatic serial numbering for expenses
* 💻 Clean and responsive UI using Bootstrap

## 📁 Categories Supported

Users can classify expenses into:

* 🍔 Food
* ✈️ Travel
* 🎬 Entertainment
* 📦 Others

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Aseeb369/SpendSmart.git
```

### 2. Navigate to Project Folder

```bash
cd SpendSmart
```

### 3. Restore Packages

```bash
dotnet restore
```

### 4. Run Migrations

```bash
dotnet ef database update
```

### 5. Run the Project

```bash
dotnet run
```

Open in browser:

```text
https://localhost:xxxx
```
